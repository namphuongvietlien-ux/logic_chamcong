CHAY PHAN MEM DOI SOAT CHAM CONG
================================

1. Copy NGUYEN thu muc AttendanceApp sang may khac (khong chi file .exe).
2. Double-click AttendanceApp.exe
3. Dat cac file nay cung thu muc voi AttendanceApp.exe (hoac chon bang nut trong app):
   - File Excel van tay
   - Thu muc Images (moi NV mot subfolder)
   - (Tuy chon) Employee_Master_Data.xlsx de nhap lan dau vao CSDL

Nhan vien / phep / ngay le / chot cong: sua tren the trong app.
CSDL: file hr_system.db (hoac data\tas.db neu may da dung ban cu) NAM CANH AttendanceApp.exe.
Khi cap nhat phan mem: chi thay AttendanceApp.exe + thu muc _internal.
GIU NGUYEN file .db — khong xoa, khong copy de len.
Trong app: nut "Cap nhat" (goc phai) kiem tra GitHub Release.
OTA can file AttendanceApp.zip (ca thu muc exe + _internal) dinh kem Release.
Sao luu: nut "Sao luu CSDL" tren the Chay Phan Tich hoac Bang dieu khien.

Khong can copy file mau CCONG / K9 — chung da nam trong goi phan mem.

Khong can cai Python. May: Windows 10/11 64-bit.

Sua gio: the "Xu ly Ngoai le" — xem theo ngay hoac theo ten nhan vien.
Ca dem: tick "Tang ca qua dem (+1 ngay)" roi nhap gio RA.
